# VPNGATE-LITE v3.14 图标候选 · 设计说明

> 设计专用稿件，不改代码。定稿权在 Leo，本文件只给推荐与依据。
> 现有文件（`assets/make_icon.py`、`assets/icon.ico`、`src/tray.rs`、
> `src/bin/vpngate-gui.rs`、`build.rs`）一律未动；新增文件只在
> `icon-candidates/` 下。

## 0. 共同母稿（三个方案共用）

- **底板**：实色靛蓝 `#1E40AF` 圆角方块（与 v3.13 同色、同 UI 选中色），
  无渐变、无阴影（Win32 指南：≤24px 不用阴影）。圆角半径 ≈ 尺寸的 21%
  （256px 时约 54px，与 v3.13 一致）。
- **图形**：一个白色粗笔画符号，单隐喻、单元素；笔画 ≥ 3px（16px 下），
  元素全部落在内侧 80% 安全区内。
- **档位**：16 / 24 / 32 / 48 / 256 五档全给。24/32/48/256 由母稿矢量
  4 倍超采样渲染；**16px 是手绘像素稿**（逐像素定坐标，非 256px 缩放）
  ——这正是 v3.13 托盘难看的根因（256px 直缩 16px）的对症解法。
- **规范依据**：Microsoft Learn《Design guidelines for Windows app icons》
  （https://learn.microsoft.com/en-us/windows/apps/design/style/iconography/app-icon-design，
  2026-11-08 核实）：48×48 网格起稿、外圆角 2px / 内圆角 1px（@48px）、
  先定剪影再上色、形状越少越好；另有“图标里不要放 baked-in 文字”的
  明确建议。对照物：v2rayN / NekoBox / Clash 类工具图标——单色底 +
  一个粗笔画符号，深浅任务栏都可读。
- **对比度实测**：白字 on `#1E40AF` ≈ **8.7:1**；靛蓝底板 on 浅底
  `#F2F2F2` ≈ 7.7:1，均远超 3.0:1 要求。唯一弱项：靛蓝底板 on 深色
  任务栏 `#1E1E1E` 仅 ≈ 1.9:1（底板边缘偏隐），但白色图形 on 深底
  ≈ 16.7:1，识别靠图形本身承载——三个方案皆如此，与 v3.13 同级。
  若定稿后想再强化深色托盘，可在托盘专用 16px 稿上加一圈细浅色描边
  （留给实现阶段决定，不在本稿内）。

## 1. 候选方案

### A · `v-bold/` —— 保留 V，但重做

- **一句话隐喻**：V = VPNGate / VPN 的首字母，沿用 v3.12–v3.13 已建立
  的品牌符号，零学习成本。
- **相对 v3.13 改了什么**：笔画 40→48/256（16px 下约 3px）；顶点
  y 0.77S→0.78S、两臂顶端外移（62→51/256），两臂在 16px 下不再
  挤成一团；臂端由圆头改为平头（去掉 v3.13 两端的圆 blobs，那是
  “风扇 / 领结”感的来源之一），只保留顶点圆角。
- **16px 像素稿**：3px 臂宽、上下各留 3px 边距、顶点尖在第 12 行，
  逐行手排（`icon-16.png`）。
- **为什么 16px 可读**：两臂 3px 粗、顶部间距 6px（第 3 行两臂
  x=2–4 与 x=11–13），V 形轮廓在 16px 下仍是两条分开的斜线加一个尖底。
- **深浅底表现**：深浅底都只靠白 V 识别，表现一致；深底上底板边缘
  稍隐（见 §0），但 V 本身对比极强。

### B · `shield/` —— 盾牌（非字母）⭐ 推荐定稿（见 §4）

- **一句话隐喻**：盾 = 安全 / 保护，VPN 客户端最直接的承诺；
  盾牌是系统托盘里最常见的“安全类”符号，用户无需学习。
- **画法**：单一元素——白色盾形外框（描边带 ≈ 0.11S，16px 下 2px），
  内部无对勾、无钥匙孔、无第二元素；盾形顶部平、两侧直、底部收尖。
- **为什么 16px 可读**：2px 描边带在 16px 下完整闭合，顶部横边、
  两侧竖边、底部尖角三处特征齐全；剪影测试里盾形一望即识。
- **深浅底表现**：三方案中深浅底最稳——白色外框包住一块与底板同色
  的“暗芯”，整个图标在小尺寸下仍是一个实心块 + 亮框，视觉重量最大，
  在深色任务栏上也不散。

### C · `tunnel/` —— 隧道拱门（非字母）

- **一句话隐喻**：拱门 = 隧道口，字面对应 VPN tunnel（一端进、一端出）。
- **画法**：单一连通图形——粗拱带 + 两条腿 + 底部横条（“路面 /
  门槛”），拱内开口即隧道洞口；拱带宽 0.13S，16px 下腿宽 3px、开口宽 4px。
- **为什么 16px 可读**：拱顶 2 行实心、两腿 3px、底条 1px，门洞形状
  完整；但“隧道”含义在 16px 下需结合上下文——单看更像拱门 / 门洞。
- **深浅底表现**：与 A、B 同级；大尺寸（48/256px）下拱门 + 路面
  的隧道感最强，是三方案中“大尺寸最好看、小尺寸最吃亏”的一个。

## 3. 16px 实测结论（看图说话，以对照图与剪影为准）

| 方案 | 16px 放大看 | 16px 剪影（黑白） | 1:1 真实尺寸 | 结论 |
|---|---|---|---|---|
| A v-bold | V 清晰，两臂分开、顶点尖，无“风扇/领结”糊团 | V 一望即识 | 可辨认为 V | **可读 ✓**，v3.13 的糊团问题已解决 |
| B shield | 盾框完整闭合，底部尖角可见 | 盾形一望即识 | 可辨认为盾牌 | **可读 ✓**，三方案中 16px 下最稳 |
| C tunnel | 拱门完整，拱顶、双腿、底条都在 | 可辨认为拱门/门洞，但“隧道”含义弱 | 可辨认为小拱门 | **可读 △**：图形可读，隐喻需上下文 |

三方案在 24px 及以上全部清晰，无可读性问题；分水岭只在 16px
（即托盘场景）。深色底与浅色底对照图上三方案表现一致，无方案
在某一主题下翻车。

## 4. 推荐定稿：B · shield（盾牌）

**理由**：

1. **16px 下最稳**：剪影测试里盾形是三方案中唯一“去色、去底板、
   只剩黑白线条仍一眼即识”的图形；V 在 16px 下虽可读，但两条斜线
   的容错余量最小（笔画稍糊即回退到 v3.13 的风扇感）；tunnel 在
   16px 下的拱门语义最弱。
2. **符合规范**：唯一同时满足“单隐喻、零文字、剪影先行”三条的方案；
   V 违反“图标不放文字”的建议（见 §5）。
3. **语义最通用**：盾 = 安全，不依赖用户知道 VPNGate 或 VPN 的英文；
   在系统托盘一众图标中，盾牌造型的辨识度高于一个字母。
4. **深浅通吃**：白框 + 暗芯的结构在深色任务栏上视觉重量最大，
   托盘场景（正是本次返工的起因）表现最好。

**但这只是推荐，不是定稿**——最终由 Leo 定。若 Leo 更看重品牌
连续性（v3.12–v3.13 已用 V 两代），A · v-bold 是次选，且本次重做
已解决其 16px 糊团问题；若 Leo 想要最直白的 VPN 字面隐喻，
C · tunnel 在大尺寸下最好看。

## 5. V（字母）vs 非字母图形的取舍

|  | V（字母） | 非字母图形（盾 / 隧道） |
|---|---|---|
| **优点** | 品牌连续：v3.12–v3.13 已用 V 两代，用户已见过；与产品名 VPNGate / VPN 首字母直接对应 | 符合 Microsoft“图标不放 baked-in 文字”规范；图形语义跨语言；剪影更独特，不易与其它字母图标撞形 |
| **风险** | ① 违反规范建议；② 16px 下字母天生易糊——两条斜笔画一挤就成扇形/领结，v3.13 的教训正在于此，本次靠 3px 笔画 + 手绘像素稿缓解，未根除；③ 字母 V 在托盘里与其它 V 字头应用无区别 | ① 品牌识别从零开始：老用户第一眼认不出是原来的 VPNGATE-LITE；② 隐喻需一次学习（盾=安全较直觉，隧道=VPN 需想一下）；③ 若日后换名，图形隐喻与名字脱钩 |
| **适用** | 看重连续性、且接受“字母图标”这一折中 | 看重规范合规与长期辨识度、愿付一次品牌切换成本 |

一句话：**V 保连续、担规范与小尺寸风险；盾/隧道合规范、担重新认牌成本。**
推荐盾，是因为本次返工的直接起因就是 16px 托盘难看——在这个取舍里，
小尺寸稳健性的权重应高于品牌连续性。

## 6. 若定稿后进入实现（给后续任务的备忘，不在本任务内做）

1. `.ico` 须用**各档原生 PNG**打包（16/24/32/48/256 五档——注意
   v3.13 的 `.ico` 缺 24px 档，本次补上），不要从 256px 缩放生成小档。
2. `src/tray.rs` 改为直接取 `.ico` 里的 **16px** PNG 交给 tray-icon，
   不要再解码 256px 再由 Windows 缩放。
3. GUI 的 `ViewportBuilder` 加 `with_icon`，窗口图标不再靠 exe 默认回退。
4. 托盘在深色任务栏上若仍嫌底板边缘偏隐，可单给托盘 16px 稿加一圈
   细浅色描边（只改托盘档，不动其它档）。
5. 图 2（资源管理器旧地球图标）已核实是 Windows 图标缓存未刷新或旧版
   文件夹所致，与本次设计无关；新图标装机后若仍显示旧图，清图标缓存
   （`ie4uinit.exe -show`）即可。
